# MCQEXAM Admin 2026
Firebase Hosting static single-page admin app. Requires valid Firebase web configuration in `public/firebase-config.js` and first admin approval in Firestore `admins/{authUid}` with `{active:true}` created manually from Firebase Console. Read `README_TAMIL.md` before deploying. Run `npm install -g firebase-tools`, `firebase login`, `firebase use mcq-exam-project`, `firebase deploy --only hosting,firestore:rules`. Existing Flutter client must filter papers by `published == true`. Results are client-scored and not tamper-proof. Review security rules before deploying.
